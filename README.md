# 🚀 3-Month Intensive Data Science & AI Roadmap

An intensive 12-week roadmap designed to rebuild core software engineering and data science fundamentals, build a production-ready portfolio, and prepare for AI and Data Analyst roles.

---

## 🛠 Tech Stack & Environment
* Primary Language: Python 3.10+
* Data & Analytics: NumPy, Pandas, SQL (SQLite/PostgreSQL), Seaborn, Matplotlib
* Machine Learning: Scikit-Learn, XGBoost, LightGBM, Optuna
* Deep Learning & AI: PyTorch, Hugging Face Transformers
* Deployment & Tools: Git/GitHub, Streamlit, FastAPI, Docker, VS Code

---

## 📅 Roadmap Overview

### 🔹 Month 1: Data Analysis, Manipulation & EDA
* Week 1: Python Fundamentals, Data Structures, OOP & Git Workflow
* Week 2: Data Wrangling with NumPy, Pandas & SQL Queries
* Week 3: Exploratory Data Analysis (EDA) & Data Visualization
* Week 4: 🏆 Project 1: End-to-End E-Commerce Data Analytics & Insights

### 🔹 Month 2: Machine Learning & Model Deployment
* Week 5: Supervised Learning (Regression & Classification Models)
* Week 6: Unsupervised Learning & Advanced Ensemble Methods (XGBoost)
* Week 7: Hyperparameter Tuning & Building Web Interfaces with Streamlit
* Week 8: 🏆 Project 2: Customer Churn / Price Prediction Web App

### 🔹 Month 3: Deep Learning, Natural Language Processing & APIs
* Week 9: Deep Learning Core Concepts & Neural Networks in PyTorch
* Week 10: Computer Vision / NLP Basics & Pretrained Hugging Face Models
* Week 11: Production-Ready API Development using FastAPI & Docker
* Week 12: 🏆 Project 3: AI-Powered Text/Image Processing Microservice
